# 首次客户固定接待素材目录

本目录存放首次客户接待时固定发送的案例视频。

## 所需文件

请将以下文件放入此目录：

### 视频文件（首次接待自动发送）
- `case_video_01.mp4` — 案例视频 1（例如：工厂/展厅/安装案例）
- `case_video_02.mp4` — 案例视频 2（例如：实际项目应用场景）

### PDF 文件（暂时不在首次接待自动发送）
产品手册暂不自动发送，如有需要可手动发送或后续配置：
- `product_catalog_01.pdf` — 产品手册 1（例如：LED 显示屏）
- `product_catalog_02.pdf` — 产品手册 2（例如：LCD 商业屏/IFP）

## 说明

- 更换素材时只需替换此目录中的文件，无需修改代码
- 视频建议时长：30秒~2分钟
- 视频格式推荐：MP4（H.264）
- PDF 建议：A4 横向，单文件不超过 10MB
